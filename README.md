# 🎓 Gradly — Student Academic Platform

**Gradly 2.0 is coming soon — stay tuned!** 🚀

Gradly is a student-focused platform being developed to bring academic tools and useful student services together in one place.

## 🎯 Vision
Make academic planning and everyday student tasks simpler through a unified, accessible digital experience.

## 🧭 Project Direction
- Academic tools and student utilities
- A cleaner, more connected student experience
- Iterative improvements based on real student needs

## 🚧 Development Status
Gradly is under active development. Features and implementation details may change as the platform evolves. Check the source code and repository activity for the latest progress.
